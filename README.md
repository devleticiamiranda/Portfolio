# 💼 Portfólio Pessoal

## 🌐 Página Web Profissional - Apresentação & Contato
Projeto desenvolvido para consolidar minha presença online como desenvolvedora Front-end, apresentando minhas principais competências, biografia e canais profissionais de contato.

## 🚀 Sobre o projeto
Este projeto consiste em um portfólio web pessoal, construído com foco em semântica, organização de estilos e design responsivo. A interface foi planejada para transmitir uma identidade visual moderna e elegante, combinando tons escuros com pontos de destaque cromático.

A aplicação conta com navegação entre páginas para dividir a apresentação inicial da trajetória pessoal, além de botões direcionando para redes de contato profissional e links externos.

## ✨ Funcionalidades
- 🧭 **Navegação estruturada**  
Menu de cabeçalho fluido para transição entre a página principal (`Home`) e a página biográfica (`Sobre mim`).

- 🎯 **Apresentação profissional**  
Seção de boas-vindas com chamada de impacto, descrição de competências e fotografia de perfil em destaque.

- 🔗 **Acesso direto às redes**  
Botões interativos integrados com ícones vetoriais direcionando para LinkedIn e GitHub.

- 🎨 **Identidade visual consistente**  
Padronização de cores e tipografias (*Krona One* e *Montserrat*) através do uso de variáveis CSS (`:root`).

- ✨ **Efeitos e interatividade**  
Estilização de estados `:hover` nos botões de contato, proporcionando feedback visual imediato ao usuário.

- 📱 **Design totalmente responsivo**  
Adaptação de layout via Media Queries, reorganizando elementos com Flexbox (`column-reverse`) para garantir usabilidade perfeita em smartphones, tablets e desktops.


## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3 (Flexbox, CSS Variables & Media Queries)
- Google Fonts (Krona One & Montserrat)
